Machine

$npx wayback dev ./my-app

How it works

Stop restarting the whole flow to see one animation again.

01

Run it

Point it at any Vite project. Your files stay untouched.

02

Drag back

Every timer, animation and reply rewinds with it. Pause freezes all of it.

03

Branch

Act from the past and a new timeline starts. The old one stays one click away.

CLI

One command. That's the setup.

wayback dev <project>Run the project's own dev server with the timeline docked at the bottom.
wayback dev . --port 4000Pick the port.
wayback dev . --code-branchesCode changes branch the timeline too.
wayback initPrefer it in the repo? Prints the two lines for vite.config.
⌥PPlay / pause⌘Hold and click to add a note?wayback=0Skip for one load
